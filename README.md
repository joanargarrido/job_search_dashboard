# Job Search Dashboard

A lightweight Kanban-style dashboard for tracking job applications throughout the hiring process. Built with Next.js and React, the app helps you keep an overview of your pipeline, move opportunities between stages, and add new roles as you search.

## What this project does

This project is a personal job application tracker designed to help you:

- monitor every application from initial interest to final outcome
- visualize applications by stage: Wishlist, Applied, Interviewing, Rejected, and Offer
- drag and drop items across columns to reflect progress
- add new jobs with company, role, salary, date, and notes
- review a quick overview of totals by status on the home dashboard
- keep the experience responsive and easy to use on desktop and smaller screens

## Main features

- Dashboard overview with counts for each application stage
- Trello-like board for organizing job applications
- DnD interactions to move applications between statuses
- New job modal for quickly recording a fresh opportunity
- Structured application metadata: company, role, salary, date applied, and notes
- Responsive side navigation and theme-aware styling
- Mock data to simulate a working job search flow without needing a backend

## Project structure

```text
app/
  board/
    components/
    page.tsx
  settings/
    page.tsx
components/
lib/
  data/
  hooks/
```

Key folders:

- `app/` contains the application routes and board UI
- `components/` holds shared layout and navigation components
- `lib/` stores mock data, formatters, and custom hooks
- `public/` contains static assets generated by Next.js

## Getting started

### Prerequisites

- Node.js 20 or newer
- npm

### Install dependencies

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

Then open http://localhost:3000 in your browser.

### Production build

```bash
npm run build
```

### Lint the project

```bash
npm run lint
```

## How the app is organized

### Overview page

The home screen shows a summary of how many applications are in each stage of the process.

### Board page

The board page is the main job search workflow. Each column represents a stage, and each card represents an application. You can:

- drag cards between columns
- update status from the card dropdown
- add a new application with the `New Job` action

### Settings page

The settings page currently describes the workspace behavior and general preferences of the dashboard.

## Notes

This project is intentionally frontend-focused and uses local mock data rather than a database or API. It is a good starting point for a personal job-tracking app or a foundation for a larger system with persistence, authentication, and analytics.
